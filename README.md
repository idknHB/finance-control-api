# Finance Control API

REST API for personal finance management developed with Spring Boot.

## Features

- Register incomes and expenses
- Manage financial transactions
- Calculate current balance
- Categorize transactions
- RESTful endpoints

## Endpoints

- `GET /lancamentos/tipo/{tipo}`: lists transactions of the supplied type (for example, `/lancamentos/tipo/receita`).

## Technologies

- Java 21
- Spring Boot
- Spring Data JPA
- Maven
- H2 Database
- PostgreSQL (future)
